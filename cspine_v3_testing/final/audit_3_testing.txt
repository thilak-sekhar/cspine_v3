================ METRIC GLOSSARY ================
Accuracy : share of images whose predicted CDI equals the true CDI (exact hit). Strict for a 4-grade scale.
Macro-F1 : F1 per class averaged with equal weight; punishes ignoring rare classes.
QWK (quadratic weighted kappa) : agreement beyond chance where an error of 2 grades costs 4x an error of 1 grade. 0 = chance, 1 = perfect. The standard metric for ordinal grading.
Within-1 : share of images predicted within one grade of the truth. NOTE: always predicting CDI 1 already scores 0.84 here, so only values clearly above that mean something.
AUC macro : how well predicted probabilities rank cases, averaged over the 4 grades (0.5 = coin flip, 1 = perfect).
auc_abn / auc_mod / auc_sev : AUC for the yes/no questions 'CDI>=1?', 'CDI>=2?', 'CDI=3?'. balacc_* : balanced accuracy of the same questions (average of sensitivity and specificity; fair even when classes are unequal).
Why not plain accuracy for 'normal vs abnormal': 78% of images are abnormal, so always answering 'abnormal' already gets 78%.
Bootstrap 95% interval : the metric recomputed on 1000 random re-draws of the images; the true value probably lies inside. 100 test images give wide intervals (about +-0.09 for accuracy).
Paired bootstrap : both models are scored on the same re-drawn images; if the interval of (B minus A) excludes 0, B really is better.
Ensemble : the 5 fold-models are averaged. TTA : each test image is also shown rotated by +-3 degrees and the answers are averaged.

================ HOW TO READ THIS HONESTLY ================
1. A ladder step counts as a contribution only if its paired-bootstrap interval excludes 0 on cross-validation (400 images). The 100-image test set is a confirmation, not the proof.
2. If the auxiliary-heads steps (E3 -> E4/E5/E6) are NOT significant, say so. The paper then claims the ordinal + clinical-fusion model and reports the auxiliary heads as a tested idea with no significant gain.
3. Exact 4-class accuracy near 0.5-0.6 is expected: expert findings alone only reach about 0.66 (random forest check), so the grade itself is partly subjective.
4. Report age+sex-only (R0) next to every image model. The image model must beat it for the claim 'the image adds information'.
5. Limitations to state: single centre, 500 images, no external validation, retrospective data, no patient IDs (we checked near-duplicates only), ROI boxes unusable, one annotator pool.
